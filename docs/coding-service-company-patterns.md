# Service-company campus coding patterns (research notes)

Sources reviewed (public interview experiences / guides — **patterns only**, not proprietary questions):

- TCS NQT 2024–2025 (GeeksforGeeks experiences): 1–2 coding Qs; arrays/strings/matrices; easy if-else; fixed sliding-window subarray sum of size k; string transforms / compression in interviews.
- Infosys InfyTQ: string reverse/palindrome/frequency; array min-max/rotate/sum; digit math / primes; occasional pattern printing.
- Accenture campus: typically **easy–moderate** coding (array logic, subarray decrement-style logic).
- Nagarro OAs: heavy on **hashing + strings + arrays** (frequency, common prefix themes, basic sliding window).
- Persistent: aptitude + fundamentals coding (AMCAT-style), not FAANG-hard graphs.
- Dassault Systèmes campus: aptitude + several basic coding / OOP-oriented tasks (string reshape, patterns).
- Impetus / similar service firms: fundamentals-first campus screens.
